# Feature requests

1. **Public Alexa+ Web Simulator for self-hosted MCP URLs** — lets independent developers test real voice + screen
   behaviour. *Priority: Critical.*
2. **Alexa+ MCP Apps rendering guide** (Echo Show viewports, touch + voice patterns, how `ui/message` maps to
   speech). *Priority: Important.*
3. **Speech-to-text confidence / phoneme hints passed to MCP tools** (e.g. in `_meta`) — would let education
   add-ons like SpeakLoop give acoustic pronunciation feedback. *Priority: Important.*
4. **Per-household learner identity in tool calls** (stable, privacy-preserving profile id) so add-ons can keep
   state per family member. *Priority: Important.*
5. **Bedrock sandbox/credits for hackathon entrants.** *Priority: Nice-to-have.*
