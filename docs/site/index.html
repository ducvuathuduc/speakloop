Honest status

Alexa+ add-on tooling is partner-only, so SpeakLoop runs in a browser simulator that is a real MCP client. The phone-level scorer is an optional install (open wav2vec2 weights, ~1.2 GB) and is not yet reachable from the simulator's microphone. Details in the README.
